Build a Python web application that acts as the "Source of Truth" for every tenant. It must merge data from ScooPilot with manual configurations to generate a complete tenantConfig JSON for the Retell AI Agent.

1. Static Settings (The "Standardized" Layer):

Backchannel Protocol: Hardcode the following backchannel words into every JSON output: "Gotcha", "Right", "I see", "yeah", "yes", and "ok".

Spelling Protocol: Set the AI to clarify ambiguous emails/names using Common Words (e.g., "A as in Apple," "B as in Banana," "C as in Car") instead of NATO phonetics.

Call Handling: Disable voicemail detection; the system is strictly for Inbound Receiving.

2. Mandatory Onboarding Modules (The "Deep Logic" Capture):
The UI must provide fields for every operational variable in the agent JSON:

Geospatial Selection (Map-Based): * ZIP Mode: An interactive Leaflet.js map where tenants click to select/deselect ZIP code polygons.

Radius Mode: A "Headquarters" pin with a slider to define a circular service territory (0–50 miles).

The Pricing Matrix: * Input fields for One-Time, Weekly, and Bi-Weekly cleanups based on dog counts (1, 2, 3, 4+).

Standardized Yard Size multipliers (Small, Medium, Large).

Initial Cleanup Surcharges based on accumulation levels (Light, Medium, Heavy).

Operational Rules:

Disposal Policy: A dropdown for "Haul-Away" or "Customer's Bin".

Access Rules: Custom text for gate codes and aggressive dog protocols.

Guarantees: A text area for the specific "Satisfaction Guarantee" read-back.

Booking Rules: Minimum lead time required for new appointments.

3. Integration & Sync Logic:

Lead Mapping: Collect and store the tenant's specific x-api-key to be injected into the CREATE_LEAD and check_availability tools.

Data Merge: Query https://app.scooppilot.com/api/retell/tenant-profile to pre-fill known data, but allow these onboarding inputs to act as the Override.

Distance Verification: Build a backend Python utility using geopy that checks if a caller is inside the territory by first checking the ZIP List and then calculating the Radius Distance.

Every File Generated by this Engine:
tenant_config.json: The absolute record including identity, pricing, and all operational policies.

territory_data.json: The coordinates and ZIP strings for the verification engine.

agent_handbook.md: A synthesized Markdown document the AI uses as its internal knowledge base.

api_credentials.json: The secure mapping of tenant IDs to their specific Replit and ScooPilot API keys.
