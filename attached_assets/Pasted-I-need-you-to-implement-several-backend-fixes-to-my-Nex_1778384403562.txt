FILES TO CREATE

1. /lib/telnyx-verify.ts
Verifies Telnyx webhook signatures using Ed25519. Uses TELNYX_PUBLIC_KEY env var. Checks the telnyx-signature-ed25519 and telnyx-timestamp headers. Rejects webhooks older than 5 minutes. Returns a boolean.

2. /lib/rate-limit.ts
In-memory rate limiter. Limits per identifier (phone number). Max 20 requests per 10 minutes per identifier. Cleans up expired entries every 30 minutes. Exports checkRateLimit(identifier) returning { allowed, remaining, resetInMs }.

3. /lib/sms-session.ts
Session management for SMS conversations. Session expiry is 24 hours of inactivity. Exports: loadSession(fromNumber, toNumber) — returns messages array or null if not found or expired. createSession(tenantId, fromNumber, toNumber, messages). updateSession(fromNumber, toNumber, messages).

4. /lib/sms.ts
Telnyx SMS utility. Exports formatE164(phone) — converts 10 or 11 digit numbers to E.164 format, throws on invalid input. Exports sendSMS(to, from, message) — sends via Telnyx SDK using TELNYX_API_KEY.

5. /lib/alert.ts
Slack alerting utility. Only fires when ALERT_ENV=production. Uses SLACK_ALERT_WEBHOOK. Exports sendAlert(message, context). Never throws — catches its own errors. 

6. /lib/validate-lead.ts
Lead validation. Required fields: tenantId, firstName, lastName, phone. Recommended fields: email, streetAddress, zipcode. Exports validateLead(payload) returning { valid, missingRequired, missingRecommended }.

7. /lib/fallback-log.ts
Logs never-invent fallback triggers to the fallback_log table. Exports logFallback({ tenantId, channel, triggerPhrase, agentResponse }). Exports isFallbackResponse(response) — returns true if response contains "i'm not certain about that". Never throws.

8. /app/api/sms/inbound/route.ts
Handles inbound SMS from Telnyx webhooks. POST handler. Steps in order:
- Read raw body as text
- Verify Telnyx signature using telnyx-verify.ts — return 401 if invalid
- Parse JSON
- Ignore non message.received events
- Extract fromNumber, toNumber, incomingText from payload
- Check rate limit using fromNumber — return 429 if exceeded
- Look up tenant from DB by telnyx_from_number matching toNumber — return 404 if not found
- Load session using sms-session.ts — create new session if null
- Append incoming message to messages array
- Build system prompt with tenant data injected (businessName, serviceArea, services, pricing, policies, hours, booking_rules, addons, guarantees, escalationPath)
- Call Anthropic API at https://api.anthropic.com/v1/messages using model claude-sonnet-4-20250514, max_tokens 300, with the messages array
- If Claude response contains SUBMIT_LEAD:{...} on its own line, parse the JSON and POST it to /api/retell/create-lead with leadSource sms, then replace that line with a confirmation message
- Check if response is a fallback using isFallbackResponse — if so call logFallback
- Append agent reply to messages, update session
- Send SMS reply via sendSMS
- Return 200

POST handler. Steps in order:
- Parse request body

We'll be in touch to confirm your cleanup appointment." Recurring message: "Hi {firstName}, thanks for reaching out to {businessName}! We'll be in touch to get your recurring schedule set up." Detect recurring by checking serviceFrequency is not one of: one-time, onetime, one time.
- Wrap SMS in try/catch — never block lead creation if SMS fails
- Return { success: true }
