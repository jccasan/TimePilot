You are redesigning the invoicing system for Scoopilot, a route-based field-service SaaS.

CONTEXT
The current invoicing system is functional but behaves like a generic invoice list.

That is not sufficient.

This product serves recurring home-service businesses.
Their primary concern is:
- getting paid
- tracking cash flow
- minimizing manual invoicing work

GOAL
Transform invoicing from a passive list into an active revenue and collections system.

CORE PRINCIPLE
Invoices are not documents.
They are cash flow events.

--------------------------------------------------

PRIMARY FEATURES TO BUILD

1. Revenue Dashboard (top of page)

Display:
- This Week Revenue
- Outstanding Balance
- Overdue Amount
- Collected This Week

These should be visually prominent and update dynamically.

--------------------------------------------------

2. Batch Actions (critical)

Add bulk actions:
- Generate invoices for selected period
- Send all unpaid invoices
- Charge all autopay customers

These should be clearly visible and easy to use.

--------------------------------------------------

3. Invoice Grouping

Group invoices by:
- Unpaid
- Overdue
- Paid
- Draft

Unpaid and Overdue should be visually dominant.

--------------------------------------------------

4. Automation-first design

Invoices should be generated from:
- completed jobs
- recurring schedules

Minimize manual invoice creation.

--------------------------------------------------

5. Autopay system

Make autopay first-class:

- show which customers are on autopay
- allow bulk charging
- retry failed payments
- show payment method status

--------------------------------------------------

6. Invoice detail view

Improve detail screen to include:
- services performed
- service dates
- clear pricing breakdown
- payment status
- payment method

Make it obvious what the invoice represents.

--------------------------------------------------

7. Collections tools

Add:
- send reminder
- auto-reminder rules
- retry failed payments

--------------------------------------------------

UX REQUIREMENTS

- clean, modern UI
- action-oriented layout
- minimal friction
- clear hierarchy
- mobile-friendly but optimized for desktop

--------------------------------------------------

IMPLEMENTATION

- React components
- reusable invoice list, dashboard, and detail components
- clean state management
- support batch operations efficiently

--------------------------------------------------

DELIVERABLES

- redesigned invoicing dashboard
- batch action system
- improved invoice list
- improved detail view
- autopay controls
- collections tools
- production-ready code

--------------------------------------------------

SUCCESS CRITERIA

The invoicing system should:
- reduce time to bill customers
- reduce unpaid invoices
- increase cash collection speed
- minimize manual work
- feel like a financial control center

IMPORTANT
Think like a service business owner.
Optimize for getting paid, not for generating documents.
