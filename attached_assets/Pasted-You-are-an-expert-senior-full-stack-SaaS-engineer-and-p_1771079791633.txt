You are an expert senior full-stack SaaS engineer and product architect. Build “Scoopilot” — a vertical SaaS for pet waste removal businesses (poop scooping). This must be production-oriented (auth, tenancy, billing, auditability), but ship an MVP fast.

TECH STACK (use exactly this unless impossible)
- Frontend: Next.js (App Router) + TypeScript + Tailwind
- Backend/API: Next.js Route Handlers (or a small FastAPI service if needed for background jobs)
- Database: Postgres (use Prisma ORM)
- Auth: Auth.js (NextAuth) with email+password and magic link option
- Payments: Stripe (subscriptions + per-seat add-ons)
- File storage: S3-compatible (or Supabase storage) for proof-of-service photos
- Deploy: Replit defaults
- Testing: lightweight (playwright optional)

CORE PRINCIPLES
- Multi-tenant: one “Company” per customer account. Every record belongs to a Company.
- RBAC: Owner, Admin, Tech. Tech has limited access (today’s route only, notes, photo upload).
- Simple UI: fast, minimal taps, mobile-first for technicians.
- MVP focus: implement only the critical workflows. Defer route optimization and advanced AI.
- Seed data: include a demo company with a few clients, properties, and recurring services.

MVP SCOPE (V1)
1) CRM
- Contacts (clients/prospects), Properties (service addresses), Tags, Notes, Attachments
- Lead status pipeline: Lead → Estimate → Active → Paused → Cancelled
- Fast search and filters (frequency, route/day, status)
- CSV import/export (Sweep & Go / Jobber style mapping; provide a simple mapper UI)

2) Scheduling + Recurring Services
- Create recurring schedules: weekly/biweekly/monthly
- One-time cleanups
- Vacation hold and skip service
- Drag-and-drop reschedule (basic)
- Recurring job engine: generate Visits for the next 4–8 weeks on a schedule; allow manual override

3) Route Management + Technician Mobile
- Routes: define Route/Day (Mon/Tue etc) and assign techs
- Technician mobile view:
  - Today’s route list
  - Tap into job: notes, gate code, instructions
  - “Start” / “Complete” with timestamps
  - Upload proof-of-service photo
  - Add internal note / report issue
- Must be extremely simple and fast

4) Invoicing + Payments
- Stripe subscriptions:
  - Plan “Run” ($49.99/mo) includes 1 user
  - Add users at $7/mo each (per-seat)
- Client payments:
  - Store card on file (Stripe Customer)
  - Auto-charge day before scheduled service OR weekly batch (make this configurable per company)
  - Failed payment workflow: mark invoice failed, create task/notification
- Basic revenue report: MRR, last 30 days revenue, failed payments count

5) Client Portal (basic)
- Client login (separate “Client” role linked to Contact)
- View upcoming service dates
- Update payment method
- Download invoices/receipts
- Pause service / request extra service (creates a request ticket)

6) Automations (light V1, no GHL dependency)
- Event-driven automations:
  - Lead created → task “Send estimate”
  - Service completed → send review request email/SMS (stub)
  - Failed payment → notify owner
- Implement as internal “Automation Rules” table + simple trigger runner (no external platform)

DEFER (explicitly do NOT build in V1)

- GPS tracking beyond timestamps
- Full marketing suite
- “AI Employees” beyond basic summaries
- White-label custom domains (leave placeholder)
